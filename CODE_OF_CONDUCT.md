# Code of conduct

HyperQuant follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be respectful and constructive. Critique ideas, code and numbers, never people.
- No harassment, insults, personal attacks, or sexual or discriminatory language or imagery.
- Do not publish anyone's private information, including wallet addresses tied to a person, without their consent.
- Do not use the project's spaces to promote trades, signals, paid groups or investment products.

## Scope

This code applies in all project spaces (issues, pull requests, discussions and reviews) and when you represent the project elsewhere.

## Reporting

Report unacceptable behaviour privately to [the maintainer](https://github.com/rdemb). Reports are handled confidentially. The maintainer may edit or remove contributions and temporarily or permanently ban contributors who break this code, following the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant.
